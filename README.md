# Vite + TypeScript minimal scaffold

This is a minimal Vite + React + TypeScript scaffold created to replace the previous Next.js site.

Scripts:

- `npm install`
- `npm run dev`

Migrate components from the old Next.js `my-page/src/app` into `src/components` and pages into `src`.
